Every problem our agent was scored on: the task as the agent saw it, how each arm did on it, why the failures failed, and a short note on what makes it easy or hard. Click a row, or link to one as problems.html#<id>.

WHAT IS AND IS NOT HERE

Shown: the prompt and the docs/ specifications exactly as the dataset gives them (rendered from Markdown), and the names and sizes of the given RTL and testbench files. Not shown: the hidden tests and harness files, which would make contamination worse, the contents of the given code files, and the files the reference solution writes, which the agent is never told.
